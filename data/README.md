# Dataset Documentation

This folder contains information about the dataset used for the Supply Chain Performance and Inventory Optimization Analysis project.

## Data Sources

The project dataset consists of Excel and CSV files containing supply chain-related information.

## Data Handling

- Original files will be preserved unchanged during the initial data audit.
- Data quality issues will be documented before cleaning.
- Sensitive or restricted data will not be published in this repository.
- Dataset structure, tables, and relationships will be documented as they are examined.

## Status

Dataset inspection and data auditing are in progress.
